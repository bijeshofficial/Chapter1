# Chapter 1 — Café & Bar

Website for **Chapter 1**, a café & bar in Lisbon, Portugal.

> Every chapter starts with a story.

Built with [Next.js](https://nextjs.org) (App Router), React 19 and Tailwind CSS v4.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

- `src/app/` — layout, page and global styles
- `src/components/` — Navbar, Hero, Story, Menu, Visit, Footer
- `src/data/menu.js` — food & drinks menu (edit prices/items here)
- `public/` — logo and printed menu images

## Editing content

- **Opening hours** — `hours` array in `src/components/Visit.js`.
- **Menu** — `src/data/menu.js`.
- **Links (socials, maps, reviews widget)** — `src/data/site.js`.
